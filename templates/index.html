CV = population standard deviation ÷ mean. Sentence, punctuation, and function-word components use 0.90 − 0.80 × clip((CV − 0.10) ÷ 0.70). Vocabulary uses 0.90 − 0.80 × clip((50-word TTR − 0.45) ÷ 0.40). Clip limits its input to 0–1.

Each 50-word TTR is unique words ÷ 50, averaged across consecutive full blocks. Any incomplete final block is excluded. Punctuation counts only , ; : — – ( ) [ ] { }.

Stylometric score = (four components) ÷ 4

Values shown to six decimal places; classification uses unrounded scores.
